# Multistreams.tv

[Multistreams.tv](https://multistreams.tv) is a multi-platform livestream dashboard for watching Twitch, YouTube, Kick, and Rumble streams together in one customizable view.

Build layouts, follow creators across platforms, discover live channels and clips, save and share stream setups, earn watch-time badges, unlock daily collectible rewards, and use AI-assisted search to find livestream content.

The site is designed to make following multiple communities simple, fast, and enjoyable from one clean dashboard.
